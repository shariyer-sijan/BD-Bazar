# BD-Bazar

## Project Name
BD-Bazar

## Description
BD-Bazar is a simple and user-friendly online product price tracking website. It helps users check product prices and find products easily. Users can see which products have increased or decreased in price. The website has a clean design and is responsive for mobile, tablet, and desktop devices.

## Technologies Used
- Next.js
- React.js
- JavaScript
- Tailwind CSS
- DaisyUI
- React Toastify
- REST API
- HTML

## Features
1. **Product Listing:** Users can view different products on the website.
2. **Product Details:** Users can click on a product to see its details.
3. **Price Tracking:** Users can check product price changes.
4. **Price Drop Section:** Users can easily find products whose prices have decreased.
5. **User Authentication:** Users can sign up and sign in.
6. **Social Login:** Users can sign in using Google and GitHub.
7. **Responsive Design:** The website works on mobile, tablet and desktop devices.
8. **Easy Navigation:** Users can easily browse different sections of the website.
